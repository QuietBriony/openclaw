Session Loop

Observe

Read runtime state

Music producerHabits, genreTimbreKits, signatureCells, humanGroove, chill preview state, and namima mood traces.

Generate

Print candidate command

drum-floor can generate into live/candidates only. OpenClaw v1 prints the command and waits.

Inspect

Check before arm

Candidate inspection is read-only. Ableton, EP-133, live slots, and Music REC stay manual.

Merge

Turn listening into PRs

Human listening notes become small repo-specific tuning changes, with copy and asset safety checked.

Producer Desk Routing

Music Chat

Intent source

This chat names the musical direction, acceptance gates, and which organ should change.

OpenClaw

Session contract

OpenClaw turns the direction into manifest, dry-run commands, and human-gated runbooks.

Repo Agents

Small patches

Each repo gets one bounded role: Music, chill, drum-floor, or namima. No cross-repo sprawl.

Human

Listen and approve

Arm, record, merge, release, and reference-copy checks stay human decisions.

Guardrails

No auto arm. Candidates never move into armed or device state by themselves.
No audio capture. No samples, microphones, waveform excerpts, lyrics, or uploads.
No copy engine. References become production judgment, not melodies, chords, or song forms.

OpenClaw v1 is intentionally boring infrastructure: JSON manifest, connector registry, dry-run CLI, browser runtime state, local trace references, and PR review gates.
