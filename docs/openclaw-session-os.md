# Music Stack OpenClaw Session OS

This repo is the Music Stack OpenClaw Desk: a session operating surface for the
QuietBriony Music Stack repo family, not a new instrument and not the global
OpenClaw mothership/runtime lane.

The guiding split:

- `Music`: integrated experimental producer runtime.
- `drum-floor`: pocket and groove candidate generator.
- `chill`: soft piano memory and quiet room reference.
- `namima`: GI mood, water interaction, and local trace context.

OpenClaw observes the organs, asks for candidates, and holds human gates. It
does not become the musician.

## Why A Separate Repo

Keeping OpenClaw separate prevents the final runtime from accumulating connector
concerns. `Music` can stay focused on sound, while OpenClaw holds session
contracts, dry-run plans, connector boundaries, and review rituals.

## V1 Bias

V1 uses boring primitives on purpose:

- JSON manifest
- connector registry
- Python stdlib CLI
- browser runtime state
- localStorage trace references
- GitHub PR review as the merge gate

MCP, OSC, MIDI, DAW bridges, and remote agents belong in later PRs after the
manifest and gates prove stable.

## Copy Safety

References are translated into production judgment:

- restraint
- pocket
- soft room
- GI mood
- rubber edit
- transparent void
- ghost pressure

OpenClaw must not copy melodies, chords, song structures, samples, lyrics, or
signature recordings from reference artists.
